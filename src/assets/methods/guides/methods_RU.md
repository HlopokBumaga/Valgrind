# **Методы шифрования данных**

В программе реализовано 3 метода шифрования:
- XOR-шифрование
- Шифр Цезаря
- Шифр Виженера

Данные шифры были выбраны, так как они являются основополагающими для изучения криптографии. Также они просты для изучения, но в меру надёжны при правильном их использовании.

---

### **XOR-шифрование**

**Шифр исключающей дизъюнкции** (**XOR-шифрование**) — шифр, основанный на логической операции **ИЛИ-НЕ** (исключающая дизъюнкция, XOR).

Суть шифра заключается в том, чтобы преобразовать каждый символ открытого текста и ключа в двоичное числовое значение и провести операцию XOR между ними.

Данная операция выполняется для каждого символа открытого текста, после чего результат операции преобразуется в десятичную систему счисления. Для кодирования символа в числовое значение и наоборот можно использовать стандарт ASCII, **UNICODE** (используется в "Valgrind") или собственный алфавит символов.

Чтобы расшифровать текст, необходимо провести операцию в обратном порядке с ключом, который использовался для шифрования исходного текста.

---

### **Шифр Цезаря**

**Шифр сдвига** (**шифр Цезаря**) — шифр, основанный на сдвиге символов по алфавиту на определённое фиксированное значение.

Суть шифра заключается в том, чтобы изменить каждый символ открытого текста путём его сдвига вправо или влево по алфавиту на фиксированное значение — ключ.

Для сдвига по алфавиту **вправо** ключ должен быть **положительным числом**, а **влево** — **отрицательным**.

Для расшифровки необходимо произвести сдвиг по алфавиту в обратном порядке, то есть применить шифр Цезаря к шифротексту, поменяв знак ключа на противоположный исходному.

---

### **Шифр Виженера**

**Шифр Виженера** — шифр, основанный на сдвиге символов по алфавиту на переменное значение.

Шифр Виженера является модифицированным шифром Цезаря, но с переменным значением сдвига, которое меняется от символа к символу. Шифрование выполняется по следующему алгоритму:

1. Кодовое слово циклически записывается так, чтобы оно соответствовало длине открытого текста.

2. Выбирается символ открытого текста и соответствующий ему символ ключевого слова.

3. Символ открытого текста сдвигается по алфавиту на определённое значение — позицию соответствующего символа ключевого слова в алфавите.

Таким образом, происходит шифрование каждого символа открытого текста. Переменность сдвига достигается выбором ключевого слова, в котором будет минимальное количество повторяющихся символов. Расшифровка аналогична расшифровке шифра Цезаря.
