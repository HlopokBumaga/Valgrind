# **Шифрование данных в программе "Valgrind"**

```
Внимание! Программа создана в рамках моего выпускного проекта. Использовать её в реальных условиях для шифрования действительно важной информации запрещено.
```

### **Шифрование информации**

Алгоритм шифрования:
1. В главном меню выбрать режим шифрования (кнопка слева).

2. Ввести данные для шифрования.

3. Выбрать метод шифрования из выпадающего списка.

4. Ввести ключ два раза.

5. Подтвердить шифрование и получить результат.

```
Результатом являются:
- Шифротекст.
- Контрольная сумма, высчитанная путём хэширования шифротекста и ключа.
```

Эти данные необходимо передать получателю.

### **Расшифровка информации**

Алгоритм расшифровки:
1. В главном меню выбрать режим расшифровки (кнопка справа).

2. Ввести данные для расшифровки.

3. Выбрать метод расшифровки из выпадающего списка.

4. Ввести ключ и контрольную сумму.

5. Подтвердить расшифровку и получить результат.

```
Результатом являются:
- Расшифрованный текст.
- Результат сравнения контрольных сумм:
Если контрольные суммы совпадают, то данные целы и подлежат использованию.
Если контрольные суммы не совпадают, то данные не подлежат использованию.
```

### **Возможные ошибки**

- ```invalid method: the encryption method is not selected``` - не выбран метод шифрования.
- ```Confirmation error: keys do not match``` - ключи не совпадают.
- ```invalid data: there is nothing to encrypt``` - не введены данные для шифрования.
- ```invalid key: the key must be ...``` - некорректный ключ.
